# Observability

## Purpose

Observability helps admins and operators understand platform health, workflow progress, agent behavior, connector status, LLM usage, and validation runtime.

## Health Areas

- System health
- Worker health
- PostgreSQL connectivity
- Redis connectivity
- Temporal workflow status
- Connector health
- Artifact storage health

## Runtime Metrics

- Failed jobs
- Agent execution logs
- Token usage
- LLM latency
- API latency
- Connector latency
- Validation job runtime
- Reconciliation job runtime

## MVP Scope

MVP should include a basic system health page, backend health endpoint, worker status, and lightweight failed-job visibility.

## Future Scope

Future observability can include dashboards, alert routing, historical metrics, trace IDs, workflow replay links, and cost/token optimization reports.
